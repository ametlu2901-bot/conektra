Preguntas frecuentes

Preguntas frecuentes sobre WhatsApp Business API

Si tu duda no está aquí, escríbenos por WhatsApp o a hola@enlazastudio.com.

¿Qué diferencia hay con la app de WhatsApp Business?

La app es para atender a mano desde el celular. La API permite automatizar, conectar con sistemas y que varias personas atiendan de forma ordenada.

¿Necesito tener mi negocio registrado?

Meta pide verificar el negocio para algunas funciones. Te explicamos qué documentos necesitas según tu caso.

¿La API es gratis?

Activarla no tiene costo de Meta, pero Meta cobra ciertos mensajes según su tarifa por país. Te lo mostramos con números claros.

¿El número sigue siendo mío?

Sí. Todo queda a nombre de tu negocio; nosotros solo lo configuramos y lo conectamos.
